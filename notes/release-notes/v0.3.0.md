# Release v0.3.0 — Advanced Dam Studio integration

## Summary
Claude's feature-rich GPU water and dam-failure simulator is included as a new Advanced Dam Studio in the Waterflow website, alongside the original MapLibre Terrain Lab.

## Changes
- Add /studio/ with GPU flood solver, dam and reservoir, progressive breach, raised transparent water, terrain undo, downstream cross sections, hydrographs and five cinematic views.
- Keep the original fast point-source and globe map at /.
- Link both tools and transfer initial geographic coordinates.
- Build Studio with Node in existing Docker image; serve via FastAPI.
- Protect data fidelity by requiring explicit ?demo=1 for generated terrain and persistent warnings.
- Add restricted public raster tile proxy and compare project implementations.

## Fixed
Correct Studio license metadata to GPL-3.0 and remove silent synthetic DEM fallback.

## Known issues
Independent simulation state is not exchanged; manually verify browser/WebGL rendering and public imagery/DEM in real network conditions. Neither engine is engineering calibrated.

## Upgrade
Run docker compose up -d --build. No database migrations. Classic remains at /, Studio at /studio/.
