# Release v0.2.0 — Cinematic Flow Tracking

## Summary
Adds immersive map-based movie mode with an illustrated raft or water tracer that follows modeled hydraulic flow.

## Changes
Wet-cell tagging, flux-based tracer advection, smooth 3D camera following, chase/aerial/wide views, raft and dot markers, in-browser path recording and replay, CSV export, slower cinematic rate, automated tests.

## Fixed bugs
No unrelated bug fixes.

## Known issues
Unvalidated model; passive tracer is not an actual buoyant raft or safe travel forecast. No collisions, structures or true water-surface mesh. Route replay does not rewind flood heatmap. No video file export. Manual browser testing remains required.

## Upgrade steps
Rebuild Docker image with docker compose up -d --build. No schema migrations.

## Rollback notes
Return to the previous v0.1.0 commit. All scenario state is transient.
