# Sprint 003 requirements — GPU engine integration

Compare Claude's independently developed Waterflow application with Classic v0.2 and retain high-value features. Keep current Classic UI and functionality; integrate Claude's functional Three.js/WebGL2 application on the same deployment and hostname rather than attempting an unvalidated in-place shader port. Include dam building, reservoir water volume, progressive breach, 3D water surface, flood-path stations and multi-angle cinematic controls through GPU Studio. Provide clear bidirectional navigation, single Docker build, independently test both engines, preserve source provenance and release versioning. Do not imply shared scenario state or validated flood predictions.

Out of scope: merging numerical kernels, automatic cross-mode scenario migration, guaranteeing MP4 video output, advanced auth, public hosting, real-world hydraulic certification.
