# Sprint 001 acceptance criteria

- [ ] Real-world DEM loads or reports provider error without a made-up fallback.
- [ ] Map can be zoomed/rotated/tilted edge-to-edge.
- [ ] User paints excavation/raised terrain and 3D map geometry updates.
- [ ] Point discharge and duration can be changed.
- [ ] Worker produces non-negative water depth and animation without blocking map controls.
- [ ] Flood overlay represents current and maximum depths; probes show meaningful numbers and arrival time.
- [ ] Sample stations present peak elevations/depths and arrival data at chosen distance increments; CSV export is correct.
- [ ] Globe toggle supports zoomed-out Earth navigation.
- [ ] Resets discard previous flood after changing terrain/source.
- [ ] Imagery has attribution, source/grid labels and an experimental hazard disclaimer.
- [ ] Backend automated tests run; browser and Docker checklist completed before release.
